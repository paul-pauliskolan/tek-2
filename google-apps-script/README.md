# Quizstatistik

1. Oppna kalkylarket `Quizstatistik Teknik 2` och valj **Extensions > Apps Script**.
2. Ersatt innehållet i `Code.gs` med koden i denna mapp och spara.
3. Valj **Distribuera > Ny distribution > Webbapp**.
4. Kor som: **Jag**. Atkomst: **Alla**.
5. Kopiera webbadressen som slutar med `/exec`.
6. Klistra in adressen i `QUIZ_STATISTICS_ENDPOINT` i `js/main.js` och publicera kurswebben.

Varje elevs forsta rattning pa en sida skickar ett anonymt svar per fraga. Inga namn, e-postadresser eller IP-adresser samlas in.
